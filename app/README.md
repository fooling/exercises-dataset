# 囚徒健身 · 徒手训练手册

基于本仓库 `data/exercises.json`（1324 个动作）构建的**手机端 webapp**，聚焦徒手训练（Convict Conditioning 体系）+ 挂墙单杠。

## 启动

```bash
python3 app/build/build.py          # 构建数据（改了 catalog.py 后需重跑）
python3 app/server.py               # 监听 0.0.0.0:9876
```

`app/public/data/app-data.json` 是构建产物，不入库，首次使用必须先跑 `build.py`。

服务器默认监听 `0.0.0.0`，局域网内任意设备都能访问；启动时会打印本机的
局域网地址，手机在同一网络下直接打开即可。也可以自己指定：

```bash
python3 app/server.py --host 0.0.0.0 --port 9876
```

iOS Safari / Android Chrome 可「添加到主屏幕」当作 App 用。

## 它做了什么

从 1324 个动作里筛出 **174 个**可徒手或挂墙单杠完成的动作，归入《Convict Conditioning》六艺体系：

| 动作族 | 数量 | 说明 |
|---|---|---|
| 俯卧撑 | 21 | 推 · 靠墙 → 单臂 → 直臂支撑俯卧撑 |
| 引体向上 | 26 | 拉 · 肩胛引体 → 标准引体 → 单臂 / 双力臂 / 前后水平 |
| 深蹲 | 17 | 腿 · 扶物深蹲 → 手枪蹲 |
| 举腿 | 21 | 核心 · 死虫 → 悬垂直腿举 → 悬垂折体 |
| 桥 | 16 | 后链 · 骨盆后倾 → 反向平板桥 |
| 倒立撑 | 6 | 肩 · 肩胛俯卧撑 → 倒立撑 |
| 臂屈伸 / 核心稳定 / 小腿 / 代谢体能 / 拉伸灵活 | 67 | 辅助与恢复 |

每个动作都带教练视角的内容：**发力要点**（按执行顺序）、**常见错误**、**三级推荐组数**（打基础 / 进阶 / 精通）、**节奏 · 组间休息 · 每周频率**。

三个入口：
- **六艺** — 六条进阶链，点进去是从入门到大师的完整阶梯
- **动作库** — 按部位 / 难度 / 动作族筛选 + 搜索
- **今日训练** — 选水平 + 重点 + 可用器械，自动排一节课（热身 / 主项 / 收尾）

## 目录结构

```
app/
├── build/
│   ├── catalog.py     ← 精选目录：难度、部位、发力要点、组数（改这里）
│   └── build.py       ← 与 exercises.json 合并，产出 app-data.json
├── public/            ← 前端（原生 JS，零依赖）
│   ├── index.html  style.css  app.js
│   └── data/app-data.json   ← 构建产物
└── server.py          ← 静态服务器，同时映射仓库根的 images/ videos/
```

## 修改内容

编辑 `app/build/catalog.py` 里的动作条目，然后重跑 `build.py`。
`build.py` 会校验每个 `id` 是否存在于数据集并检查重复收录，写错会直接报错退出。

新增一个动作：

```python
E("0652", "标准引体向上", "pull", 3, ["背", "手臂", "核心"],
  cues=["正握，握距略宽于肩", "先肩胛下沉后收，再屈肘", "..."],
  errors=["借摆动起身", "不放到底"],
  std=("1组×5次", "2组×10次", "2组×15次"),   # 可省略，按难度自动生成
  need="单杠", note="挂墙单杠请先确认膨胀螺栓牢固。"),
```
